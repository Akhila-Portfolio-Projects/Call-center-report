# Call-Center-Performance-Dashboard

## Project Overview
This project focuses on analyzing call center performance using Microsoft Excel. The dashboard provides an overview of call volume, call duration, call trends, customer ratings, and representative performance.

The dashboard helps understand call center operations and identify patterns in call activity and performance.

## Project Objectives
- Analyze the overall number of calls.
- Track call trends across different months.
- Analyze call amounts and call duration.
- Compare female and male callers across different cities.
- Understand customer ratings.
- Evaluate call center representative performance.
- Identify happy callers and monitor average ratings.

## Tools Used
- Microsoft Excel.
- Pivot tables.
- Pivot charts.
- Slicers and Interactive filters.
- Excel dashboard visualization.
## Dashboard Features
- Total calls.
- Total Amount.
- Total Call Duration.
- Average Rating.
- Happy Callers.
- Monthly Call Trend.
- Female vs Male Callers by City.
- Customer Rating Analysis.
- Representative-wise Call Analysis.
- Representative-wise Amount Analysis.
## Key insights
- The dashboard provides an overview of total calls and call center activity.
- Monthly call trends help identify changes in call volume throughout the year.
- The gender comparison chart shows the distribution of female and male callers across cities.
- The rating chart helps understand the distribution of customer ratings.
- Representative-wise analysis helps compare call volumes and amounts across representatives.
- KPI cards provide a quick summary of overall call center performance.
## Conclusion
This project demonstrates how Microsoft Excel can be used to organize, analyze, and visualize call center data through an interactive dashboard. It helps prevent key performance indicators and makes it easier to understand call center performance.
